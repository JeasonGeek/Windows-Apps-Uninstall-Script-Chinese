# Windows-Apps-Uninstall-Script-Chinese
# 介绍
可以卸载常见的Windows10/11自带应用
参考了一些github icerayer的脚本[icerayer/WinAppsUninstaller](https://github.com/icerayer/WinAppsUninstaller/tree/main)
用于卸载 Windows 10/11 系统中的预装应用，需调取powershell
